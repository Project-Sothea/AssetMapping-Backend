Sync Flow in Backend:

Device Updates (raw)
        │
        ▼
Conflict Consumer (resolve conflicts → write DB)
        │
        ▼
device_projections topic
        │
        ▼
Projection Consumer (update Redis)
        │
        └──> produce “ready-to-pull” event
                   │
                   ▼
        Notification Consumer (WebSocket to device)
                   │
                   ▼
               Device pulls from Redis



                  ┌─────────────────────┐
                  │      Device 1       │
                  │ (offline/online)    │
                  └─────────┬──────────┘
                            │ Push Updates
                            │
                            ▼
                  ┌─────────────────────┐
                  │ Conflict Consumer   │
                  │ (resolve conflicts  │
                  │  → write DB)        │
                  └─────────┬──────────┘
                            │ Produce authoritative events
                            ▼
                  ┌─────────────────────────────┐
                  │ device_projections topic    │
                  │ (post-conflict authoritative│
                  │ events)                     │
                  └─────────┬───────────────────┘
                            │
                            ▼
                  ┌─────────────────────────────┐
                  │ Projection Consumer         │
                  │ - Updates Redis             │
                  │ - After Redis update:       │
                  │   triggers notification     │
                  └─────────┬───────────────────┘
                            │ WebSocket “ready-to-pull”
                            ▼
                  ┌─────────────────────────────┐
                  │ Device Pulls via API        │
                  │ - API reads from Redis      │
                  │ - Fetches only changed      │
                  │   entities                  │
                  └─────────────────────────────┘
